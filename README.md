# Unity Icon Studio

Editor local e estático para criar ícones consistentes de scripts da Unity.

**Site:** https://unity-icon-studio.ngamerandroid.chatgpt.site

## Recursos

- template vetorial 64 × 64 com dobra, faixa, contorno e sombra;
- presets branco, azul, rosa, roxo e vermelho;
- glyphs internos e importação segura de SVG;
- posição, escala e rotação do glyph;
- rótulo opcional e ajustável;
- prévia em 64, 48 e 32 px;
- exportação SVG e PNG em 64, 128 ou 256 px;
- processamento totalmente local no navegador.

## Desenvolvimento

```bash
npm install
npm run dev
```

## GitHub Pages

O workflow em `.github/workflows/pages.yml` gera o site estático e publica o diretório `out`.

## Licenças dos glyphs

Os glyphs desenhados diretamente neste repositório fazem parte do projeto. SVGs importados pelo usuário mantêm suas licenças originais. Verifique a licença da fonte antes de distribuir um ícone final.
